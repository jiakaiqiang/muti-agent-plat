## 四、关键上下文与决策

### 4.1 Runtime 流式契约
- 内部 `RuntimeStreamFrame` 不进 shared 合同,通过 `frame-to-runtime-event.ts` 转 `AgentRuntimeEvent`。
- v0.2 首选 `AgentRuntimeRunHandle/start()`；`stream?/cancel?` 只作为一个兼容周期的 deprecated 双轨接口。
- `RunChannel` 是 handle 内部使用的有界单消费者异步迭代器。
- `LivenessWatchdog` 处理首帧超时 + 空闲超时 + 绝对超时。
- 心跳降级:adapter 未实现 `stream?` 时 orchestrator 走 `runtime_progress` 合成心跳。

### 4.2 Actor 契约 v0.2 双写期
- 新增字段: `CollaborationEvent.actor?: ActorRef`, `AgentTask.assignee?: ActorRef`, `AgentTask.assignedBy?: ActorRef`。
- 旧字段 `fromAgentId / assigneeAgentId / assignedByAgentId` 用 `@deprecated` 注释,**v0.2 双写,v0.3 移除**。
- `events.service.create` 单点推导 actor,上游 orchestrator 数十处调用不需要改动。
- 前端 `useActor.ts` 优先读 `event.actor`,缺失时回退 `fromAgentId`。

### 4.3 Session Resume 设计
- Runtime 侧: `AgentRunResult.runtimeSession.cliSessionId/workDir` 显式写入 `RuntimeInvocationLog`。
- Orchestrator 侧: `RuntimeService.findPriorInvocation` 查同 `(sessionId, agentId, taskId, runtimeType)` 最近 `completed` invocation。
- 派发侧: `buildResumeOptions(phase, prior)` 仅在 `task_execution` 阶段塞 `options.resume`。
- Adapter 侧:
  - Codex: `workDir` → cwd，`cliSessionId` → app-server `thread/resume`
  - Claude: `workDir` → cwd, `cliSessionId` → args `['--resume', <id>]`
- resume 失败或 session id 不一致时，RuntimeService 清除 resume 并 fresh start 一次，同时发出 `RESUME_FALLBACK`。

上述历史错误均已修复；2026-07-10 最终 `npm run typecheck` 通过，不再存在本交接记录列出的基线豁免。
