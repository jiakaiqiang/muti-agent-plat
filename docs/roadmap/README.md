# Roadmap Docs

本目录存放修复路线图和执行计划。

- `remediation-plan-v1.md`：方案级修复计划，负责定义批次、目标和优先级。
- `remediation-execution-plan-batch2-3.md`：执行级任务计划，负责拆解具体批次任务。
- `multica-refactor-completion-execution-plan-v1.md`：Multica 对标 R1～R7 补全执行计划；Claude/PostgreSQL/Redis/Workdir 环境验收已完成，Codex 上游阻塞；P1 Skill 前端完成，Watchdog 真实样本基线待执行。
- `unfinished-tasks-v2.md`：v2 未完成任务清单，负责承接可插拔 Engineering Runtime、Context Router 和协作主线之后的后续工作。
- `coordinator-controlled-routing-phase1-tasks.md`：Coordinator 中心流转第一阶段任务清单。
- `context-v2-session-evidence-remediation-plan-v1.md`：旧会话来源、v2 Evidence 补读、只读归档、版本闸门和真实发布的开发计划。
- `workflow-builder-and-agent-capability-plan-v1.md`：线性工作流当前边界、三栏低代码创建器、人工/机器人确认节点，以及 Agent 能力画像和可解释匹配路线。
- `local-runtime-cli-foundation-plan-v1.md`：Local Runtime CLI 单用户方案、当前整改计划、生产验收门禁，以及签名分发、Local Claude 和会话唤醒后续计划。

阅读时建议先看方案，再看执行计划；继续做 v2 增强时，从未完成任务清单选择下一项。
