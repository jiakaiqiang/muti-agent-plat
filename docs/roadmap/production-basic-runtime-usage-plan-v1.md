# 生产基础 Runtime 使用计划 v1

> 日期：2026-08-04  
> 状态：已登记，待后续实施  
> 关联计划：[Local Runtime CLI 基础能力计划](local-runtime-cli-foundation-plan-v1.md)

## 1. 目标

生产环境同时支持两种执行方式：

1. **服务器执行**：用户只使用浏览器，任务由服务端 Runtime/Worker 执行，不依赖用户电脑安装任何组件。
2. **用户本地执行**：用户在浏览器中选择本地模式，任务由安装在用户电脑上的 Local Runtime 执行，可访问用户授权的本地工作区。

浏览器只负责选择执行位置、展示连接状态和发起任务。浏览器不能直接启动任意本地进程，也不能替代 Local Runtime 执行本地工具。

## 2. 生产使用流程

### 2.1 服务器模式

1. 用户在创建会话时选择“服务器”。
2. 平台后端选择可用的服务器 Runtime/Worker。
3. 服务端完成工作区准备、任务执行和结果回传。
4. 用户电脑不需要安装或启动 Local Runtime。

### 2.2 本地模式首次使用

1. 用户在“本地运行”菜单或创建会话窗口中选择“本地”。
2. 平台检测当前账号是否存在在线且兼容的本地设备。
3. 未安装时，页面提供经过签名的 Local Runtime 安装包和安装状态提示。
4. 安装程序注册 `agent-runtime://` 协议、开机自启或系统服务、单实例约束和受信任的平台地址。
5. Local Runtime 通过设备码或登录授权绑定当前平台账号与设备。
6. Local Runtime 主动向平台建立 WSS 长连接；平台不要求用户电脑开放入站端口。
7. 用户在本地弹出的目录选择器中授权工作区，平台仅保存 `workspaceId` 等不暴露绝对路径的标识。

### 2.3 本地模式后续使用

1. Local Runtime 在线时，浏览器直接使用已连接设备和已授权工作区。
2. Local Runtime 已安装但离线时，浏览器通过 `agent-runtime://wake` 请求操作系统拉起本地程序。
3. 页面轮询或订阅连接状态，Runtime 建立 WSS 后再允许创建本地会话。
4. 未安装、协议未注册、版本不兼容或唤醒超时必须显示可操作的恢复入口，不能只返回通用网络错误。

协议唤醒只负责启动进程。它不等于自动恢复中断会话，也不得在连接恢复后静默重跑任务。

## 3. 通讯与部署边界

```text
用户浏览器 --HTTPS/SSE--> 平台前后端
                              |
                              +--内部调度--> 服务器 Runtime/Worker
                              |
用户 Local Runtime --WSS---->+
```

- Local Runtime 只建立出站 HTTPS/WSS 连接，适配 NAT、家庭网络和企业网络场景。
- 远程生产环境必须使用 HTTPS/WSS；仅本机开发环境允许 HTTP/WS。
- 反向代理只在 WebSocket Upgrade 请求时转发 `/local-runtime`，普通页面 GET 仍由前端应用处理。
- 自定义协议不得携带长期令牌、工作区绝对路径或任务正文；最多携带一次性关联标识。
- 本地模式与服务器模式必须显式选择。目标 Runtime 不可用时禁止静默切换执行位置。
- 本地绝对路径、文件内容和本地凭据默认留在用户设备，只有用户授权的任务结果可以上传。

## 5. 用户与设备模型

当前 `ownerId=local-user` 只适用于单用户、本机或受控内网部署。面向多个真实用户开放生产环境前，必须完成：

- 用户认证与租户边界；
- 用户与设备的所有权绑定；
- 设备令牌短期化、轮换和撤销；
- 工作区、会话和 Runtime 的授权校验；
- 管理员审计与异常设备处置。

单用户私有部署可以先交付基础生产版本；多用户公共部署不得绕过上述隔离门槛。

优先完成 Windows；macOS、Linux 和企业软件分发策略在基础闭环稳定后另行排期。

## 7. 验收门槛

- [ ] 一台未安装 Runtime 的 Windows 用户电脑可从平台下载并完成签名安装。
- [ ] 首次绑定后，重启电脑或退出再登录，Runtime 能按配置自动上线。
- [ ] Runtime 已安装但未运行时，浏览器可以请求操作系统唤醒，并在超时后给出明确处理入口。
- [ ] 用户电脑无需公网 IP，也无需开放入站端口。
- [ ] 本地目录必须由本机用户明确选择，服务端不得获得本地绝对路径。
- [ ] WSS 中断会使当前执行进入明确的中断状态，重连后不得自动重复执行。
- [ ] 不安装 Local Runtime 时，服务器模式仍可完整创建和执行会话。
- [ ] 不兼容版本会被阻止接单，并提供升级入口。
- [ ] 多用户生产启用前，验证用户、设备、工作区和会话之间不存在越权访问。
- [ ] 安装、唤醒、连接、执行、升级和卸载均有可检索日志与稳定故障码。

## 8. 明确不等同的能力

- “唤醒 Local Runtime 进程”不等同于“唤醒历史会话继续执行”。
- “浏览器检测 Runtime 状态”不等同于浏览器直接拥有本地文件或进程权限。
- “Local Runtime 自动重连”不等同于任务自动重跑。
- “服务器部署平台”不意味着服务器可以直接访问用户电脑的 `localhost`；通讯必须由用户电脑上的 Runtime 主动连向平台。
