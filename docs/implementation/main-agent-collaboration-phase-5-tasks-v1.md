## 完成定义

执行期提问不误中断，范围变更经用户选择和重确认，新需求独立排队，旧回调/重启不误执行。

完成一个任务不等于阶段完成；所有 AC 必须有证据。最后同步相关合同、测试说明与 Checklist，不修改其他未通过阶段的状态。
