# Agent Task 执行计划

本目录保存 Workspace-Aware Agent Context v2 的系统设计和细粒度执行任务。

## 入口

- [系统设计](./system-design.md)
- 任务总数：142
- 单任务预计时间：10–15 分钟
- 默认状态：pending

## 执行规则

1. 按编号顺序执行，除非任务文件明确调整依赖。
2. 每个任务先补失败测试，再修改实现。
3. 单任务超过 15 分钟必须停止并继续拆分，不得扩大范围。
4. 验收失败时只返工当前任务。
5. 完成后在任务文件的“完成记录”中填写结果、验证命令和备注。
6. 高风险、破坏性、发布、部署和真实外部 Runtime 操作仍需单独确认。
