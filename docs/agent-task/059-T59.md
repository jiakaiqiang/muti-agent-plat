- 备注：
  - 新增 `apps/server/src/modules/workspaces/workspace-apply-change-set.ts`，`applyServerLocalChangeSet({rootPath, currentRevision, nextRevision, changeSet})` 返回 `ApplyChangeSetResult`。
  - 先调用 T58 的 `validateChangeSetBaseHashes`；有冲突则返回 `ok:false` + `conflicts`，磁盘保持原状；否则按顺序执行 create/update/delete/move。

  - 现有 `apps/server/src/common/server-file-changes.ts` 是 runtime 用的旧 fileChanges 路径，本次不改动；T59 提供 workspace-plane 的应用能力供后续 provider/broker 复用。
