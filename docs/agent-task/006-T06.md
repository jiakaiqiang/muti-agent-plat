# T06 Web 显示运行版本

- 状态：completed
- 预计时间：10 分钟
- 阶段：A
- 依赖：T05

## 目标

在 Web 工作区显示前后端运行版本。

## 实施范围

packages/shared/src/contracts.ts；apps/server/src/modules/sessions、ops；apps/web 版本展示

## 测试

运行 Vue 组件测试。

## 验收标准

- 版本信息可见且不破坏现有布局。
- 测试结果必须记录在本文件的“完成记录”中。

## 完成记录

- 结果：已完成。新增 `RuntimeVersionSummary` 组件，工作区设置页可见前端版本、后端版本、构建时间、Commit 和 Pipeline 版本；组件通过 `/health` 读取后端运行版本，读取失败时显示未连接状态。
- 验证：`npm run test -w @project/web -- RuntimeVersionSummary.spec.ts`；`npm run build -w @project/web`
- 备注：前端版本读取 `VITE_APP_VERSION`，未配置时回退 `0.1.0`；后端版本字段来自 T05 的 Ops health 合同。
