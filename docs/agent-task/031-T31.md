# T31 禁止 metadata.content 正文

- 状态：completed
- 预计时间：10 分钟
- 阶段：E
- 依赖：T30

## 目标

禁止把报告正文仅放在 metadata.content。

## 实施范围

apps/server/src/modules/runtimes；packages/shared Artifact 合同

## 测试

运行 Schema 失败测试。

## 验收标准

- 非法结构验证失败。
- 测试结果必须记录在本文件的“完成记录”中。

## 完成记录

- 结果：已完成。新增 `RuntimeArtifactMetadata`，通过 `content?: never` 在共享类型层禁止 `metadata.content`；Runtime Artifact JSON Schema 通过 `not: { required: ['content'] }` 拒绝任何 metadata 正文键，即使顶层 `content` 同时存在也不允许双正文来源。
- 验证：`node ..\..\node_modules\tsx\dist\cli.mjs --test .\src\modules\runtimes\runtime-output-schema.spec.ts`（在 `apps/server` 下执行，4 项通过）；`npm run typecheck -w @agent-cluster/shared`；`npm run typecheck -w @agent-cluster/server`
- 备注：现有 Runtime 生产者审计未发现合法输出依赖 `metadata.content`；Runtime 合同已明确正文只能存放在顶层 `content`。
