  - `node node_modules/tsx/dist/cli.mjs --test apps/server/src/modules/workspaces/workspace-index/workspace-index-cache.spec.ts` 5/5 通过
- 备注：
  - 新增 `apps/server/src/modules/workspaces/workspace-index/workspace-index-cache.ts`，`WorkspaceIndexCache` 提供 `set`/`get`/`invalidateOn`/`clear`/`currentRevisionId` 五个方法。
  - `get(revision)` 只有在 revision.id 与缓存一致时返回条目，否则视为未命中；`invalidateOn(newRevision)` 在 revision 改变时清空缓存，revision 未变则保持。
  - 与 T60 的 `createWorkspaceRevision` 配合：ChangeSet 应用后可用新 revision 调 `invalidateOn` 使旧索引失效，`get(oldRevision)` 立刻返回 `undefined`。
