- 结果：`ConfirmationCard` 在 actions 非空时渲染结构化 Post Review 操作，展示补读原因与缺失路径、受限交付限制、保存当前进度和取消任务；点击原样发出 action key，且不再同时显示旧 resume/cancel。无 actions 的既有确认卡继续回退到 options。

- 备注：按 `element-plus-ui-style` 规程使用 Element Plus 风格层级：补读使用 `#409EFF` 主操作，受限交付/保存为默认操作，取消为危险操作，并加入可见键盘焦点；动作 API 分流留给 T44。
